Importer un menu depuis un PDF

Pour de meilleurs résultats, assurez-vous que votre fichier PDF contient les plats avec un format cohérent (nom, description et prix sur des lignes consécutives).
Format accepté : .pdf (taille maximale : 5 Mo)
Retour au menu

Format attendu du PDF

Structure par plat (3 lignes) :
Nom du plat
Description du plat
Prix (ex: 12.50€ ou 12,50€)
Exemple concret :
Entrecôte Grillée
Viande de bœuf grillée avec sauce au poivre
18.50€

Saumon Poêlé
Filet de saumon frais avec légumes de saison
16.00€
Points importants :
  • Le PDF doit contenir du texte extractible (pas d'images scannées)
  • Chaque plat doit avoir exactement 3 lignes (nom, description, prix)
  • Le prix doit être au format XX.XX€ ou XX,XX€
  • Laissez une ligne vide entre chaque plat
  • Tous les plats seront classés dans la catégorie "plat_principal"
Conseil : Consultez le fichier EXEMPLE_FORMAT_MENU.txt dans votre projet pour un exemple complet.
